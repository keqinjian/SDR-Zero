# 信息波 f3 渐进抗干扰调试指南

> 实验链：`competition/info/info_decoder_f3.py` + `competition/info/tx_radio2.py`  
> 稳定链：`info_decoder_f1.py` + `tx_radio.py`（保留不动，随时可回退）

## 1. 三个档位

| 档位 | RF BW | RX gain | FIR cutoff / transition | DC | 用途 |
|------|-------|---------|-------------------------|----|------|
| baseline | 1000 kHz | 45 dB | 300 / 50 kHz，Hamming | 关 | 与 f1 物理层做回归基线 |
| balanced | 600 kHz | 35 dB | 260 / 20 kHz，Blackman-Harris | 32 | 默认首测 |
| strong | 540 kHz | 25 dB | 255 / 15 kHz，Blackman-Harris | 32 | 二/三级强干扰实验 |

启动：

```bash
# f3 看门狗会自动拉起 tx_radio2，两个进程使用同一环境变量
INFO_ANTIJAM_PROFILE=baseline python3 competition/info/info_decoder_f3.py
INFO_ANTIJAM_PROFILE=balanced python3 competition/info/info_decoder_f3.py
INFO_ANTIJAM_PROFILE=strong python3 competition/info/info_decoder_f3.py
```

手动分别启动时：

```bash
RM_ENABLE_GRC_WATCHDOG=0 INFO_ANTIJAM_PROFILE=balanced \
  python3 competition/info/tx_radio2.py

RM_ENABLE_GRC_WATCHDOG=0 INFO_ANTIJAM_PROFILE=balanced \
  python3 competition/info/info_decoder_f3.py
```

同一时刻不要再运行旧 `tx_radio.py` / `info_decoder_f1.py`，因为 RPC 8081、
UDP 14346 和 SDR-B 都相同。

## 2. 联合测试矩阵

每格至少连续测试 30 秒，记录五条命令 Hz、AC、Header、CRC16 fail。

| 轮次 | 干扰 | profile | 目的 |
|------|------|---------|------|
| A1 | 关闭 | baseline | 应保持约 10 Hz，证明 f3 不回退 |
| A2 | L1 | baseline | 复现原约 5 Hz |
| A3 | L2 | baseline | 复现原 0 Hz |
| A4 | L3 | baseline | 复现原 0 Hz |
| B1～B4 | 关/L1/L2/L3 | balanced | 观察模拟带宽+窄 FIR+降 gain 的综合收益 |
| C1～C4 | 关/L1/L2/L3 | strong | 仅 balanced 不足时测试；检查无干扰是否被过窄带宽伤害 |

若需要找单变量贡献，不要直接新增档位，先在 `tx_radio2.py` 调试区临时复制档位：

1. 固定 FIR，只扫 gain：45 / 35 / 25 / 15 dB。
2. 固定最佳 gain，只扫 RF BW：1000 / 600 / 540 kHz。
3. 固定前两项，只比 FIR：300/50 与 260/20 kHz。

## 3. 日志判读

f3 每 5 秒打印：

```text
0x0A01=...Hz ... 0x0A05=...Hz
AC=... H0/1/2=...
Header=OK/FAIL
CRC8/16fail=...
strict/window=...
dedup=...
```

| 现象 | 优先判断 | 下一步 |
|------|----------|--------|
| UDP 有，AC 接近 0 | 前端阻塞、削顶或解调失锁 | 看 raw 频谱，先降 gain / 收 RF BW |
| AC 多，Header FAIL 多 | 残余邻道使硬判决错误 | 比较 260/20 FIR；下一阶段考虑 symbol_sync |
| Header OK 多，CRC16 fail 多 | 空口包误码/丢片，长帧受损 | 看 window 恢复数；下一阶段做独立 degraded partial |
| strict 有、window 主要是 dedup | 正常，窗口只作为安全兜底 | 不必追求 window 数量 |
| raw 频谱顶平 | ADC/前端已削顶 | 数字 FIR 无法补救，继续降 gain 或转硬件滤波 |

## 4. 频谱窗

`tx_radio2` 同时显示：

- `raw before FIR`：Pluto 原始 IQ，用来判断强邻道和削顶。
- `filtered`：DC/FIR 后 IQ，用来判断二/三级干扰是否被压下。

相对增益图不能直接当绝对 dBm；重点比较同一现场、同一档位切换前后的形状和顶平情况。

## 5. 安全边界

- 正式 `radio/info/*` 仍只发布 CRC8、CRC16、协议长度全部通过的数据。
- 64-bit Access 最多允许 2 bit 错误，Header 必须精确为 `00 0F 00 0F`。
- 包窗口只复扫 CRC 有效帧，不把“字段看起来合理”的 CRC 失败数据混入主话题。
- `strong` 不是赛场默认答案；若 540 kHz 模拟带宽削弱信息波边缘，应退回 balanced。

## 6. 后续升级触发条件

只有 balanced/strong 的 raw IQ 未削顶、AC/Header 已恢复但 CRC 仍高时，才进入下一阶段：

1. `quadrature_demod_cf(1/sens)`
2. `symbol_sync_ff`（M&M）
3. `binary_slicer_fb`
4. 必要时再做 2.083333 Msps → 1 Msps 的 12/25 重采样

若 raw IQ 已削顶，停止继续堆 decoder 容错，转向模拟滤波、前端动态范围或第二接收通道分集。
