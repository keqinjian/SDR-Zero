# 信息波 f6 近最优接收设计与调试

## 目标

在 **不改官方空口参数**（SPS=47、Sens=1.5628、Access/Header/CRC/ROS）的前提下，尽量逼近 PlutoSDR + GNU Radio 3.8 工程可行上限：

- 可观测物理量闭环（IQ 削顶 / CFO 估计）
- 匹配滤波 + `symbol_sync(M&M+MMSE)`
- soft 符号上的 Access 相关同步
- 连续 AGC + 离散 FIR 档兜底
- IQ 录波与离线回放

## 文件

| 文件 | 作用 |
|------|------|
| `competition/info/tx_radio6_flow.py` | 物理层主图 |
| `competition/info/tx_radio6.py` | 接收入口 |
| `competition/info/tx_radio6_tunes.py` | 档位 / AGC 限幅 |
| `competition/info/info_decoder_f6.py` | 解码 + 自适应 |
| `competition/info/info_f6_iq_replay.py` | IQ 离线回放 |

## 物理层链路

```text
Pluto 1Msps
→ [complex DC 可选]
→ channel FIR（可热更新）
→ QuadDemod(1/Sens)
→ 慢偏置扣除（single_pole_iir, α≈1e-5，τ≫Header连续0）
→ Gauss 匹配滤波（BT=0.35）
→ symbol_sync(M&M+MMSE) 或回退 clock_recovery_mm
→ soft float UDP :14347
→ hard bit  UDP :14346
→ 探头：IQ / FM / soft
→ 可选 IQ file_sink（INFO_F6_IQ_RECORD）
```

## 启动

默认自适应：

```bash
INFO_F6_PROFILE=auto python3 competition/info/info_decoder_f6.py
```

比赛保守固定档（关闭大步探索，仍可读探头；`INFO_F6_AUTO=0` 关闭 RF 自动）：

```bash
INFO_F6_AUTO=0 INFO_F6_PROFILE=fixed_balanced \
  python3 competition/info/info_decoder_f6.py
```

录 IQ：

```bash
INFO_F6_IQ_RECORD=/tmp/info_f6.c64 INFO_F6_PROFILE=auto \
  python3 competition/info/tx_radio6.py
```

离线回放：

```bash
python3 competition/info/info_f6_iq_replay.py /tmp/info_f6.c64
```

不要与 f3/f4/f5 同时占用 Pluto、UDP 14346/14347、RPC 8081。

## 自适应逻辑（摘要）

每 2s：

1. 读 `get_iq_stats` / `get_fm_stats`
2. IQ `max_abs`/`rms` 过高 → **连续降增益**（不清 bit 缓冲）
3. 有有效帧 → `locked`，过弱则小升增益
4. 无帧且探头削顶 → `desense` 档（会 flush）
5. AC 有、Header 无 → `wide_fir` / `weak_boost`
6. Header 有、帧无 → `weak_boost` / `narrow`
7. 否则按档位表轮换；Access 假同步多时收到 2

## 环境变量

| 变量 | 默认 | 含义 |
|------|------|------|
| `INFO_F6_PROFILE` | `auto` | `auto` / `fixed_balanced` / `baseline` |
| `INFO_F6_AUTO` | `1` | RF/AGC 自动 |
| `INFO_F6_SOFT_SYNC` | `1` | 软相关优先 |
| `INFO_F6_SOFT_UDP_PORT` | `14347` | soft UDP |
| `INFO_F6_BIAS_ALPHA` | `1e-5` | 慢偏置系数 |
| `INFO_F6_IQ_RECORD` | 空 | IQ 录波路径 |
| `INFO_F6_ACCESS_HAMMING` | `4` | Access 放宽上限 |
| `INFO_F6_AGC_COOLDOWN_S` | `2` | AGC 冷却 |
| `INFO_F6_RECORD` | `0` | 硬比特文本录制 |

## 验收矩阵

| 场景 | 期望 |
|------|------|
| 连续 420B 自检 | 硬/软/Header/CRC 全过 |
| -40 dB + -10 dB 干扰 | 帧率不低于稳定 f3 balanced（±10%） |
| -60 dB + -10 dB 干扰 | 不低于最佳 f4/f5 固定档；增益不过度顶平 |
| 人为高增益 | 数秒内 AGC 下降，日志出现 `agc:clip` / `probe-clip` |
| 同段 IQ 回放 | softAC/Header 趋势与在线可对照 |

## 明确不做

- 无 FEC 时软猜 Payload 并发布
- 短窗判决域 `dc_blocker` 默认开启
- 抄开源 SPS=52 / 单 SDR 时分架构
- 第一期多 `air_bit_order` 枚举

## 与 f5 关系

f5：离散换档 + 硬判决 + symbol_sync。  
f6：探头真值、连续 AGC、匹配滤波、软 Access、IQ 复盘。赛场可用 `INFO_F6_AUTO=0` 接近固定接收机行为。
